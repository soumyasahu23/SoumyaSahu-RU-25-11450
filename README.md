# Strong Number Checker (Mini Project)

## Objective
This mini project checks whether a given number is a Strong Number or not using C programming.

## What is a Strong Number?
A Strong Number is a number whose sum of factorial of its digits is equal to the original number.

Example:
145 = 1! + 4! + 5! = 145

## Tech Stack
- C Programming Language
- VS Code
- GitHub

## Expected Output
- Strong Number
- Not a Strong Number

## How the Program Works
1. Store the original number
2. Extract digits using % operator
3. Calculate factorial of each digit
4. Add factorial values
5. Compare sum with original number
